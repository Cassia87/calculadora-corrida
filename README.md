# Calculadora 

Uni duas coisas que amo, programação e corrida e criei essa calculadora que mostra pace, velocidade ou tempo, de acordo com os dados inseridos. 

## ✍️ Conteúdo abordado

- Estruturas de repetição (for, while, do-while)
- Condicionais (if, else, switch)
- Orientação a objetos
- Leitura de dados com Scanner
- Cursos utilizados para fazer o projeto: Curso de Java do *Canal Fessor Bruno* e Curso de POO do *Curso em Video*.
